# petshop-powerbi-dashboard
Dashboard de vendas para PetShop desenvolvido com Power BI. Análise de faturamento por bairro, evolução temporal de vendas e KPIs.

## 📊 Sobre o projeto
Dashboard desenvolvido no curso da Alura para análise de faturamento de uma rede de petshops.

## 🎯 Principais métricas
- Faturamento total por bairro
- Evolução temporal de vendas
- Ticket médio por região

## 🛠️ Ferramentas
- Power BI Desktop
- Power Query (ETL)
- DAX
